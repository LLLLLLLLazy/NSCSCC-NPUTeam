# 

# 本项目为第十届“龙芯杯”全国大学生计算机系统能力培养大赛参赛作品。

# 

# \## 项目简介

# 

# 本项目实现了一个基于 LoongArch32 精简版指令集的双发射乱序处理器软核，采用十级流水线架构，最高运行频率为 85 MHz。

# 

# 处理器集成了分支预测、寄存器重命名、动态调度、重排序缓存、Cache、二级 TLB、MMU 和 AXI 总线等模块，支持整数指令、特权指令、异常与中断处理。

# 

# \## 测试结果

#
