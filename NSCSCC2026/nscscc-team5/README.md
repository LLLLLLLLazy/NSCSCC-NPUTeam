# NSCSCC 2026 西北工业大学六队

本设计是一款**七级顺序单发射**处理器，前端采用 8 项指令队列 IFQ 实现非阻塞取指机制，后端采用 Load Queue、Store Buffer 和四项顺序退休队列 WBQ 解耦访存与提交。

架构上允许在老 load 等待期间有限地提前完成，但所有架构状态均从 WBQ 队首顺序更新，从而保证精确异常。

# 说明

该 `src` 文件夹下的设计并非比赛提交的直接版本，但在架构上基本保持一致。我们为参考者添加了详细的注释，并以直观清晰的命名规则来对信号进行命名，在参考时容易上手。

# 成绩

**主频: 89MHz (实际可达90MHz)  IPC比: 1.123  性能分: 3.058 (90MHz对应为3.086)**

可以用 U-boot 启动 Linux 并运行指令 (不过仍存在bug，会随机出现问题，参考者请自行尝试修正)
